# MediNear Backend

MediNear is a pharmacy management and medicine discovery backend built using Spring Boot, PostgreSQL, and JWT authentication.

## Technologies

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- JWT Authentication
- Maven
- Docker
